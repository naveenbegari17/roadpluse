AWS Service Catalog & Beginner Concepts

Educational Reference

Amazon CloudFront

Planned

What it is: A fast Content Delivery Network (CDN) that delivers CSS, JavaScript, and HTML from edge servers located closest to citizens.

Current Equivalent: Vercel Edge Network / Local Static Asset Serving.
Read Official AWS CloudFront Docs ↗

Amazon API Gateway

Planned

What it is: A fully managed service that acts as the "front door" for backend applications, handling rate limiting, authentication, and routing requests to Lambdas.

Current Equivalent: Flask Route Handlers (@app.route).
Read Official AWS API Gateway Docs ↗

AWS Lambda

Planned

What it is: Serverless compute that runs Python code only when a hazard report is submitted. You don't manage or pay for idle servers.

Current Equivalent: Vercel Serverless Function (api/index.py).
Read Official AWS Lambda Docs ↗

Amazon RDS (PostgreSQL)

Planned

What it is: Relational Database Service managing automated backups, replication, and spatial indexing (PostGIS) for millions of geospatial road coordinates.

Current Equivalent: SQLite (Local) or Free Tier Cloud PostgreSQL (Neon/Supabase).
Read Official AWS RDS Docs ↗

Amazon S3 (Simple Storage)

Planned

What it is: Highly durable object storage for user-submitted pothole photos and dashcam snapshots, using pre-signed URLs to upload securely without hitting server compute.

Current Equivalent: Omitted in prototype to strictly adhere to ₹0 zero-cost budget.
Read Official AWS S3 Docs ↗

AWS CloudWatch & IAM

Planned

What they are: CloudWatch monitors API latency, error alarms, and log streams. IAM (Identity and Access Management) enforces the Principle of Least Privilege so functions only access what they need.

Current Equivalent: Python console logging and environment variable isolation.
Read Official AWS CloudWatch Docs ↗
