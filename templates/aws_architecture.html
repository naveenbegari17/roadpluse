AWS Service Catalog & Concepts

Educational Reference

Amazon CloudFront

Planned

What it is: A high-performance Content Delivery Network (CDN) delivering CSS, JavaScript, and HTML from edge locations worldwide.

Prototype Equivalent: Vercel Edge Network / Local Static Assets.
Read CloudFront Docs ↗

Amazon API Gateway

Planned

What it is: Managed entry door handling HTTPS requests, rate limiting, and routing incoming calls directly to serverless Lambdas.

Prototype Equivalent: Flask Route Handlers (@app.route).
Read API Gateway Docs ↗

AWS Lambda

Planned

What it is: Event-driven serverless compute running Python hazard risk logic on-demand. Zero idle server fees.

Prototype Equivalent: Vercel Serverless Function (api/index.py).
Read AWS Lambda Docs ↗

Amazon RDS (PostgreSQL)

Planned

What it is: Managed relational database service with automatic replication, backup snapshots, and PostGIS spatial indexing.

Prototype Equivalent: Local SQLite or Free Tier PostgreSQL (Neon/Supabase).
Read Amazon RDS Docs ↗

Amazon S3 (Simple Storage)

Planned

What it is: Infinite scale object storage for citizen-uploaded pothole photos, utilizing pre-signed URLs to upload directly.

Prototype Equivalent: Omitted in initial prototype for strict ₹0 budget adherence.
Read Amazon S3 Docs ↗

CloudWatch & IAM

Planned

What they are: CloudWatch monitors API latency, error metrics, and log streams. IAM enforces least privilege security credentials.

Prototype Equivalent: Python console logging and environment variable protection.
Read CloudWatch Docs ↗
